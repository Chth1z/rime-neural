# Architecture & Design Notes

## 1. Zero-Patch In-Process Execution Model

Official Weasel (`librime >= 1.17.0`, Lua 5.4.8) exports the Lua 5.4 C API directly from `rime.dll` and permits `package.loadlib`.

- **`src/lua_api.rs` & `build.rs`**: Dynamically probes `rime.dll` (with `librime.dll`, `lua54.dll`, and current executable fallbacks) requiring Lua 5.4-exclusive `lua_newuserdatauv` alongside the 21 required `lua_*` symbols (including `lua_version`, `lua_checkstack`, `lua_gettop`, `lua_rawget`, and `lua_rawset` for metamethod-free table access) with zero import `.lib` dependency. Enforces `(504.0..505.0)` from `lua_version(L)` before pinning the module with `GetModuleHandleExA(PIN | FROM_ADDRESS)`, ensuring Rime redeploys (`lua_close` -> `FreeLibrary`) keep ONNX Runtime worker pools and the UIA worker thread alive. All Lua C bindings and entry points use `extern "C-unwind"` with `catch_unwind` at every FFI boundary (`panic = "unwind"` in `[profile.release]`), and `build.rs` embeds Win32 `VS_VERSION_INFO` into `rime_neural.dll`.
- **`lua/rime_neural.lua`**: Calls `init_async(...)` to load ONNX Runtime in a background thread. The engine becomes ready after a successful warmup inference. Normalizes Windows path separators before `package.loadlib`, tracks failed DLL paths per path, retains the loaded native handle for cross-schema retries, auto-detects whether `option_name` is declared in `switches`, freezes UIA context per composition (`comp_ctx`) while slicing `preedit_before_caret` via `caret_pos`, resolves `.gram` paths per schema (with `shared_data_dir` fallback and `grammar/collocation_max_length`), checks the tags of the segment supplied by Rime, and retains a matching sentence snapshot across trailing punctuation. Clearing or committing the composition releases frozen context. Supports an optional `rime_neural/data_dir` override and `shared_data_dir\neural` fallback for non-ASCII Windows user profile paths, while keeping `feedback.jsonl` under the writable `user_dir\neural\` via Rust's UTF-16 Win32 APIs.

## 2. Inference Pipeline (`src/engine.rs`)

1. **Strict `sentence`-Only & Tag Gating**: Only contiguous leading candidates on configured segment tags (default `["abc"]`) with `cand:get_genuine().type == "sentence"` and matching `(start, _end)` are reranked. Exact dictionary phrases (`phrase`), userdb phrases (`user_phrase`), English words, dates, numbers, mixed uppercase/digit/auxiliary-code inputs, and punctuation pass through unchanged.
2. **Dynamic Model Architecture Introspection & Fast Cold Start**:
   - Inspects `past_enc_k` and `past_choice_k` shapes from `session.inputs()` (`[enc_layers, 1, heads, p, head_dim]` and `[choice_layers, 1, heads, p, head_dim]`), verifies required ONNX output names (`logits` and all 4 `present_*` tensors) at initialization, checks `choice_compact` in `unified_vocab.json`, and builds the no-prepend candidate tokenizer in memory by cloning the loaded tokenizer and updating `Metaspace(PrependScheme::Never)` recursively across `PreTokenizerWrapper::Sequence`.
   - Collects special/control added tokens from `tokenizer.get_added_tokens_decoder()` at startup into a dynamic first-byte trigger table, stripping control tokens from untrusted UIA context and candidate text before/after `encode_fast` while preserving ordinary vocabulary tokens (`<code>`, `<b>`, `<unk>`).
   - Configures sequential execution with a single inter-op thread (`with_parallel_execution(false)`, `with_inter_op_spinning(false)`) while preserving intra-op spinning for low-latency burst keystrokes.
   - Pre-builds 3 selective `ort::RunOptions` via `OutputSelector::no_default()`:
     - Context KV pass: fetches only `present_enc_k/v` + `present_choice_k/v`
     - Pass-1 keystroke: fetches only `logits` + `char_logits`
     - Pass-2 P2C verification: fetches only `logits`
   - Reuses per-engine `i64` / `String` scratch buffers via `TensorRef::from_array_view`, decodes `char_logits` directly from ORT's borrowed slice with precomputed per-slot allowed-char tables, merges `uv.readings` and single-char entries of `uv.ml.pinyin` into `readings` (`syl_to_all_cids` covers extended/Traditional characters `cid >= old_chars` while `old_chars` caps Simplified P2C generation), and suppresses `char_lps` for alternate segmentations. Candidate deltas and the P2C margin share the same per-slot scoring scale. The log partition cancels for in-vocabulary comparisons and is evaluated only for a fixed missing-character penalty.
3. **16-Slot Token-ID Prefix KV-Cache + 256-Entry Monotonic-Clock LRU**: Caches `(last_ctx_str, last_ctx_ids)` and keys prefix KV entries on truncated context token IDs (with empty context pinned, a single shared `true_mask` slice, and `kv_idx` reused across Pass-1 and Pass-2). The evaluation cache uses an in-place monotonic `u64` LRU clock with O(1) hit promotion, keyed by canonicalized weights, `p2c_verify_margin`, active `.gram` configuration, context, raw input, layout, and candidates.
4. **Memory-mapped single-pass `.gram` fusion (`src/gram.rs`)**: Memory-maps `Rime::Grammar/1.0` (`wanxiang-lts-zh-hans.gram`) read-only via Win32 `CreateFileMappingW` with `FILE_FLAG_RANDOM_ACCESS` and checked header validation. Schemas share one mapping per loaded path. Each evaluation selects a resident mapping and keys the result by its path, penalties and window. Uses a single-pass forward double-array trie walk (`~0.004 ms`/sentence, configurable `collocation_max_length` clamped `2..=8`) bit-identical to upstream `librime-octagram` across BMP and non-BMP UTF-8 (`〇`, CJK Ext A–I), and reuses Pass-1 `.gram` scores during Pass-2 P2C verification.
5. **5-Feature Cross-Domain Linear Fusion**:

   $$s_i = w_0 \cdot \log\operatorname{softmax}(\text{logit})_i + w_1 \cdot \ln(i + 1) + w_2 \cdot \Delta_{\text{gram}, i} + w_3 \cdot \Delta_{\text{char\_lp}, i} + w_4 \cdot \mathbf{1}_{\text{ctx}} \cdot \log\operatorname{softmax}(\text{logit})_i$$

   Default weights: `[1.0, -1.4, 0.05, 0.15, 0.0]`.
6. **KV-Cached Pass-2 Verified P2C Synthesis & Focus-Bound Context Entity Splice**: Requires full syllables, finite scores, and candidate lengths matching the slot count. When Pass-2 verification is enabled (`verify_margin > 0`), the engine batches up to 4 deduplicated proposals into a single KV-cached Pass-2 forward pass reusing Pass-1 candidate tokens:
   - **Greedy P2C proposal**: included when the novel `char_logits` string beats Rime's best candidate by `verify_margin`, placed at `#1` when `ldiff > top1_logit_diff && gdiff > top1_min_gram_diff` (or `#2` when `ldiff > top2_logit_diff && gdiff > top1_min_gram_diff - 1.5`).
   - **Maximal Context Entity Splices**: when `ctx_tail` is non-empty, `cands[best_idx]` aligns strictly with every unit's `readings`, and both baseline and spliced candidate fit within `candidate_tokens`, scans left- and right-maximal 2+ character reading-matched Han spans from `ctx_tail` and splices them (individually and as a combined non-overlapping multi-entity splice) into `cands[best_idx]`. Context-only splices add a prefix-copy bias guard (`+2.0` on `top1_logit_diff`, `+1.5` on `top2_logit_diff`) while keeping the standard `.gram` floor; each Pass-2 proposal is cached with its origin and deltas and evaluated independently in `select_p2c_placement` (`#1` beats `#2`, ties broken by `ldiff`). Zero-context keystrokes skip the splice path completely.

## 3. Universal Pinyin Recovery (`src/pinyin.rs`)

- **7 Double Pinyin layouts**: Natural (ZRM), Flypy (小鹤), MSPY (微软, `; = ing`), Sogou (搜狗, `; = ing`), ABC (智能ABC), Ziguang (紫光, `; = ing`), Jiajia/PYJJ (拼音加加). Exhaustively verified against all 3,008 derived 2-key codes in official `rime-ice` / `rime-frost` schemas, respecting explicit `'`/` ` chunk separators; invalid 2-key pairs return `None` and emit a partial unit to maintain 1:1 slot alignment.
- **Full Pinyin**: 3-phase ordered memoized `O(N * L)` alignment (exact full syllable -> bounded adjacent-letter transposition across readings and user aliases -> ASCII partial prefix) against the leading candidate's merged `readings`, respecting explicit `'` and space syllable separators, mapping `lue`/`nue` and `[jqxy]v*` aliases to canonical vocabulary syllables, and falling back to an `O(L)` dynamic-programming chunk splitter minimizing `(partial_chars, units)`.

## 4. Non-Blocking, Fail-Closed UIA Context (`src/uia.rs`)

- All COM / UIA work runs on one dedicated background MTA (`COINIT_MULTITHREADED`) thread using `CUIAutomation8` / `IUIAutomation6` with 200 ms connection and transaction timeouts, plus an `IUIAutomationFocusChangedEventHandler` for immediate snapshot invalidation and same-window password detection when focus moves; throttled same-window refresh triggers schedule a trailing deferred probe (`recv_timeout`).
- Pre-warmed asynchronously on keystrokes 1–2, refreshed after commits via `kick_uia_after_commit()` (25 ms off-thread settle delay bypassing the 35 ms keystroke throttle), and disabled cleanly when `enable_uia_context: false`.
- The worker bounds a single selection against `RangeFromChild(&focused)` (falling back to `DocumentRange`) and walks back up to 96 characters (`GetText(512)`). Normalization retains up to 64 characters before the caret and respects object and paragraph boundaries. For `ValuePattern`-only edit controls, the field value identifies empty or masked fields without assuming caret position.
- The keystroke path matches the foreground `(HWND, PID)` against a classified snapshot, while process-image lookups run on the worker. A focus change advances the epoch under the snapshot lock: probes publish only into their originating epoch, and Lua checks the same `(HWND, focus_epoch)` before reusing frozen context, reading at most the commits recorded inside that focus epoch from Rime session history on non-`TextPattern` controls, or logging a commit. Disabling UIA selects Rime session history directly.
- Fails closed on `CurrentIsPassword == true`, `CurrentIsPassword` `E_ACCESSDENIED`/COM error, `OpenProcess` `ERROR_ACCESS_DENIED` (Protected Processes / hardened credential UIs), and processes matching the denylist: password managers and authenticators (`KeePass*`, `KeePassXC`, `1Password`, `Bitwarden`, `Enpass`, `LastPass`, `Dashlane`, `RoboForm`, `NordPass`, `ProtonPass`, `Keeper`, `PasswordSafe`, `Authy`, `WinAuth`), credential/UAC UIs (`CredentialUIBroker`, `consent.exe`, `LockApp`), remote-session clients (`mstsc.exe`, `msrdc.exe`, `PuTTY`, `Xshell`, `MobaXterm*`, `FinalShell`), and local terminals (`WindowsTerminal`, `conhost`, `cmd`, `powershell`, `pwsh`, `mintty`, `alacritty`, `wezterm-gui`, `kitty`).

## 5. Zero-Plaintext Feedback & Personal MAP Tuning (`src/feedback.rs` + `scripts/tune-fusion.py`)

- At commit, the filter matches the input prefix and the selected candidate’s byte range to the scored segment. The final Rime menu supplies the displayed rank and the genuine sources before OpenCC. A choice with ambiguous sources is omitted. The logger records candidate indices for up to 64 scored candidates and writes only zero-plaintext numeric feature records (`v: 2`, `sample_weight = 1.0`, `model`, `has_gram`, `has_ctx`, `logits`, `gram_deltas`, `char_lps`, `shown_top1_idx`, `chosen_idx`). It checks the immediate parent and rotation destination by path and verifies metadata on the append handle opened with `FILE_FLAG_OPEN_REPARSE_POINT`. At 5 MiB it rotates the log by atomic replacement, retaining one `.1` backup. A transient sharing lock permits appends while the active file is below 10 MiB.
- `scripts/tune-fusion.py` reads both `feedback.jsonl` and rotated `feedback.jsonl.1` (supporting `--schema`, `--model`, `--has-gram`, `--top1-sample-rate`, and `--scrub-legacy-inplace` with Windows `PermissionError` retry), runs damped Newton-Raphson Bayesian MAP shrinkage (`(lam / Kish N_eff) * 0.5 * ||w - W_PRIOR||^2`) with Armijo backtracking line search around `W_PRIOR`, freezes `w_ctx_lp` when either context stratum has fewer than 20 training records in a fit, and scores three-decimal weights on five contiguous held-out blocks. It selects the lowest weighted NLL among updates meeting `min(N, Kish N_eff) >= 100`, the one-sided paired NLL test (Hájek SE, Bonferroni critical value Φ⁻¹(1 − 0.05/7)), non-decreasing Top-1 accuracy, and domain sanity bounds (`w_logit >= 0.1`, `w_rank <= 0.0`, `w_logit + w_ctx_lp >= 0.1`).

## 6. Opt-In Pre-Commit Local Span Repair & Literal Lock (`lua/rime_neural_repair.lua`)

- Mounted optionally at `engine/processors/@before 0` with configurable hotkeys (`rime_neural_repair/repair_key`, default `Alt+r`; `rime_neural_repair/lock_key`, default `Alt+l`; empty string disables individually). Idle keystrokes perform at most two `KeyEvent:eq` comparisons before returning `kNoop`.
- **Word-aligned pre-commit homophone repair**: inspects `cand:get_genuine():to_sentence()` (`entrys`, `word_lengths`, `entry.code:print()`) and scans the active menu for native `Sentence` alternatives differing only at the logical target word with matching byte spans and dictionary codes. Renders `[target]  1 alt1  2 alt2 ...` via a `ShadowCandidate` menu overlay without moving `ctx.caret_pos`; `1..9`/`Space` highlights the native candidate pre-commit via `seg.selected_index`, and `Escape`/toggle restores the exact original menu and index.
- **Verbatim ASCII literal lock**: arms at an empty composition, after confirmed/selected prefix segments (confirming a fully covering `sentence` in place when invoked mid-composition), or converts an eligible pending non-sentence ASCII token at end of input into a native `Segment(lo, #input)` with `tags = { raw = true }` and `status = "kConfirmed"`. Supports `[A-Za-z0-9._/%-+]`, `BackSpace` editing, bare modifier preservation, and automatic disarm on external context updates via a transient `update_notifier` connection.
